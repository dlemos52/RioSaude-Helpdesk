# Helpdesk Riosaúde

Sistema de Helpdesk desenvolvido em HTML, CSS e JavaScript.

## Estrutura
- `index.html` — estrutura da aplicação
- `css/style.css` — estilos personalizados
- `js/app.js` — lógica da aplicação
- `assets/` — imagens, ícones e documentos

## Execução
Abra `index.html` no navegador ou utilize um servidor local.
